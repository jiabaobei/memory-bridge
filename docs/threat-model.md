# 隐私威胁模型

版本：v0.1（2026-08-29） · 配套实现：`privacy.py` / `dss.py`

## 资产

1. 记忆内容（对话要点、项目上下文、偏好、凭证类信息）
2. 语义关联图（能暴露用户的兴趣结构与社交/工作关系）
3. 设备与场景标签（暴露用户的行为模式）

## 信任边界

```
┌──────────────┐   E2E 加密差分包    ┌──────────────┐
│   设备 A      │ ──────────────────▶ │   设备 B      │
│ 明文记忆库    │                     │ 明文记忆库    │
└──────┬───────┘                     └──────────────┘
       │ 密文
┌──────▼───────┐
│ 中继/云       │  只见密文与路由元数据（Phase 2 起强制）
└──────────────┘
```

- **本机**：信任设备主人；不防"设备已被物理接管"或本机恶意进程（见非目标）。
- **中继 / 网盘**：完全不信任。网盘中转通道（v0 已实现）与未来的实时中继
  都只承载密文载荷；明文写入网盘需要显式确认（`--plaintext`）。
- **对端设备**：配对后才信任（Phase 2 配对流程）；未配对设备无法解密任何载荷。

## 已实现的保证（v0）

| 威胁 | 缓解 | 位置 |
|---|---|---|
| 敏感记忆被同步/预加载出设备 | PAMS L1：`migration=local` 在差分构造与预加载候选两处硬过滤（结构保证，非策略） | `dss.compute_delta`、`heat.preload_candidates` |
| 凭证类内容被误标为可迁移 | 写入时敏感关键词自动降级 local | `privacy.default_migration` |
| 医疗/财务记忆流入无关场景 | PAMS L2：跨域预加载默认拒绝 | `privacy.preload_allowed` |
| 长期驻留的本地库被拷走 | 单文件 SQLite，可整库加密/删除（应用层整库加密 Phase 3） | 用户自控 |
| MCP 客户端越权改写记忆 | 工具面只开放 Add/Search/Preload，无改写工具 | `mcp_server.py` |
| 网盘服务商 / 云端看到记忆明文 | 差分包默认 Fernet 口令端到端加密（随机盐随包携带，PBKDF2 派生密钥），服务商只见密文；明文写入需显式 `--plaintext` | `transport.py` |

## Phase 2 将实现的保证

- 传输端到端加密（X25519 + AEAD）：中继/网络攻击者只见密文；
- 设备配对（配对码/二维码）：未配对设备收不到任何记忆；
- embedder 一致性握手：防"语义漂移"导致的静默错配。

## 非目标（v0 明确不防）

- 已被入侵设备上的本机攻击者（可读明文库）——与 1Password 等本地优先软件同界；
- 流量分析（时间/大小侧信道）——Phase 2 只做填充基元，不承诺抵抗主动分析；
- 恶意 MCP 客户端把注入上下文转发给第三方 —— 客户端侧责任，文档提示。
